# Part 0. 오리엔테이션

> 유니티 개발자 취업 문서 · 기술 문서 작성 가이드 **v2**

## 이 가이드가 다루는 것

이 가이드는 유니티(C#) 개발 지망생이 **취업 문서**와 **기술 문서**를 만들고,
그 과정을 **AI와 다이어그램 도구로 가속**하는 방법까지 한 번에 다룹니다.

```
이 가이드
├── Part 1. 취업 문서 작성 가이드      (이력서·자기소개서·포트폴리오)
├── Part 2. 기술 문서 작성 가이드      (개요→구조→기능→선택→회고)
├── Part 3. 프레젠테이션 레이아웃      (정보를 잘 전달하는 화면 구성)
├── Part 4. Mermaid 다이어그램        (클래스·시퀀스·상태·플로우차트)
├── Part 5. AI 활용 워크플로우         (웹 챗봇으로 문서 가속하기)
└── Part 6. 좋은 레이아웃 프롬프트      (복사해서 바로 쓰는 한글 프롬프트)
```

기존 가이드가 "무엇을 쓸 것인가"에 집중했다면, 이번 v2는 여기에
**"어떻게 보여줄 것인가(레이아웃·다이어그램)"** 와
**"어떻게 빠르게 만들 것인가(AI)"** 를 더했습니다.

## 두 가지 산출물

이 가이드의 결과물은 두 가지 형태로 존재하며, **소스는 하나**입니다.

| 산출물 | 형태 | 용도 |
|---|---|---|
| **Markdown 소스** | `.md` 파일 | GitHub Repo에서 바로 읽기. Mermaid 네이티브 렌더링 |
| **프레젠테이션** | Marp 슬라이드 → HTML/PDF | 발표·배포용. github.io + PDF export |

즉 여러분도 이 구조를 그대로 따라 하면 됩니다. **문서를 Markdown으로 한 번 쓰면**,
읽기용 문서와 발표용 슬라이드를 동시에 얻습니다.

## 문서 작성 도구 스택 (권장)

입문자 기준으로, 복잡한 설정 없이 시작할 수 있는 조합입니다.

- **에디터**: VS Code 또는 JetBrains Rider (Markdown 미리보기 지원)
- **문서 소스**: Markdown (`.md`)
- **다이어그램**: Mermaid — 코드로 쓰면 그림이 됨 (Part 4)
- **발표 슬라이드**: Marp — 같은 Markdown을 슬라이드로 (Part 7 배포 편)
- **AI 보조**: 웹 기반 챗봇(Claude, ChatGPT 등) — 초안·다이어그램 코드 생성 (Part 5)
- **최종 제출**: PDF (기업 보안 정책상 외부 링크가 막힌 곳이 종종 있음)

> **왜 Markdown인가?** 텍스트라서 버전 관리(Git)가 쉽고, GitHub에서 바로 렌더링되며,
> 슬라이드·PDF·HTML 어디로든 변환됩니다. 한 번 쓴 내용을 여러 곳에 재사용할 수 있습니다.

## 읽는 방법

- **당장 취업을 준비 중이라면** → Part 1 → Part 2 순서로.
- **문서는 있는데 안 읽힌다면** → Part 3(레이아웃) → Part 4(다이어그램).
- **작성 속도를 높이고 싶다면** → Part 5(AI) → Part 6(프롬프트).

> 이 가이드의 규칙은 **법칙이 아닙니다.** 목적은 하나 —
> *잘 읽히는 문서로 "함께 일하고 싶은 개발자"임을 증명하는 것.*
